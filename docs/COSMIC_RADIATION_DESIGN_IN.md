## 2. Tier B — Instrumented retrofit pilot protocol

Use before any fleet-wide soft-shield or panel proposal.

### B.1 Objectives
- Measure **effective / ambient dose** with and without the candidate shield on **comparable routes** (same aircraft type family, similar altitude/latitude bands when possible).
- Report **Δdose / Δkg** (or Δdose / Δarea density).
- Prefer **crew stations** (cockpit, jump seats, crew rest) over whole-cabin cladding.

### B.2 Candidate classes (research order)

| ID | Class | Intent | Honesty note |
| --- | --- | --- | --- |
| B1 | Hydrogenous soft layers (PE / HDPE textiles or thin panels) | Neutron component | Mass-friendly; limited high-Z role |
| B2 | Boron-loaded composites (hBN / BN fillers in polymer) | Neutron capture assist | Certification/fire gates dominate |
| B3 | Gd₂O₃ ± W composite fabrics (crew wearables) | Mixed neutron/photon trials | Flight literature: some composites ~5–10% class; single-material trials can be **null** |
| B4 | Geometry-only | Move dense/hydrogenous mass near crew | “Free” if logistics allow |

### B.3 Required measurements
- [ ] Detector type and calibration stated  
- [ ] Route, date, solar/geomagnetic context  
- [ ] Shielded vs unshielded (or pre/post) on same profile  
- [ ] Mass and thickness of shield  
- [ ] Uncertainty / environmental variance acknowledged  
- [ ] **Stop rule:** if Δdose not distinguishable from noise after agreed hours, **do not scale**

### B.4 Explicit non-goals for Tier B
- Not full-cabin metal retrofit  
- Not passenger marketing claims from a single fabric trial  
- Not a substitute for Tier A operational controls

## 3. Tier C — Design-in requirements (future airframes)

Radiation is a **first-class design constraint** alongside structures, propulsion, noise, and emissions.

### C.1 Architecture requirements

| Req | Description |
| --- | --- |
| C1 | Prefer **hydrogenous** structural or semi-structural materials where strength/fire allow |
| C2 | Evaluate **hBN–HDPE / BNNT-bearing** composites for neutron effectiveness **per mass** vs aluminum baselines |
| C3 | For **LH₂ / cryo** concepts: treat tank geometry as potential **co-benefit moderator**; place crew rest to exploit it |
| C4 | Place **crew rest / high-dwell** volumes in higher self-shield zones (center, over wing, near tanks) |
| C5 | Window belts remain higher-flux; do not site long-duration crew rest on window lines without mitigation |
| C6 | Couple optional **onboard radiation nowcast** to operational advisories (altitude/route within ATC) |

### C.2 Materials research matrix (simulation / lab first)

| Material family | Primary benefit | Gates before airframe use |
| --- | --- | --- |
| PE / HDPE / related | Neutron moderation per mass | Fire, smoke, structural role limits |
| hBN / BNNT composites | Neutron performance + stiffness paths | Processability, cost, certification |
| Gd-bearing thin layers | Localized capture | Toxicity, activation, durability |
| Al / CFRP baselines | Reference structure | Not radiation-optimized alone |
| LH₂ | Fuel + moderator co-benefit | Cryo systems, boil-off, safety |

### C.3 Design review questions (must answer)
1. What is predicted **Δeffective dose** at FL350–400, polar vs equatorial, for the proposed stack?  
2. What is **mass penalty** vs baseline mission?  
3. What **fails first**: fire, fatigue, inspectability, or cost?  
4. Does the design **still need Tier A** operational controls? (Answer should be yes.)  

### C.4 Certification honesty
Design-in research **≠** type design approval. No Air document may imply FAA/EASA/TC certification from simulation alone.
