## 2. Tier B — Instrumented retrofit pilot protocol

### B.1 Objectives
- Measure dose with/without candidate shield on comparable routes.
- Report **Δdose / Δkg**.
- Prefer crew stations over whole-cabin cladding.

### B.2 Candidate classes
| ID | Class |
| --- | --- |
| B1 | Hydrogenous soft layers (PE / HDPE) |
| B2 | Boron-loaded composites (hBN / BN fillers) |
| B3 | Gd₂O₃ ± W composite fabrics |
| B4 | Geometry-only mass placement |

### B.3 Required measurements
Detector · calibration · route/date/solar context · shielded vs unshielded · mass/thickness · uncertainty · **stop if Δdose ≈ noise**.
