## 1. Primary scientific questions

1. What is the **Δdose** (shielded − unshielded) for a specified areal density of hydrogenous (PE/HDPE) material at crew-relevant positions on a defined route class?

3. What is **Δdose per kg** (or per g/cm²) for the candidate vs “no add” baseline?

## 2. Pre-registered design

### 2.1 Route class (choose one and freeze)

| Parameter | Freeze example |
| --- | --- |
| Altitude band | FL350–FL400 |

### 2.2 Conditions

| Arm | Description |
| --- | --- |
| Control | No added shield |
| Treatment | PE/HDPE (or named composite) at stated g/cm² at **crew station** (jump seat / rest / cockpit side) |

### 2.3 Instruments

- Detector type + calibration certificate + energy/particle response notes  
- Position in cabin fixed and photographed  
- Logging interval stated  

### 2.4 Outcomes

| Primary | Ambient dose equivalent rate or effective-dose proxy as detector defines; integrated dose per flight segment |
| Secondary | Δdose/kg; variance across flights; polar vs any control route |

### 2.5 Analysis plan (pre-registered)

- Primary contrast: treatment vs control on matched segments  
- Report mean difference + 95% CI (or bootstrap)  
- **Stop / null rule:** if CI includes 0 at planned N, publish null — do not scale fleet claims  
- No post-hoc route shopping without labeling exploratory  

### 2.6 Sample size

Pilot: N flights per arm sufficient to estimate variance (e.g. 5–10 each), then power calculation for confirmatory phase. Exact N depends on detector variance — state before unblinding analysis.
